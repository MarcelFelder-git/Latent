# Screenshots

Hier liegen die Bilder fuers README. Wenn sie da sind: im README den
auskommentierten Block unter "What It Does" einkommentieren - die Pfade
stimmen dann schon.

## Welche Aufnahmen

| Datei | Inhalt |
|---|---|
| `screenshot-app.png` | Das Hauptbild. Ganzes Fenster mit einem entwickelten Foto. |
| `screenshot-vergleich.png` | Der Vergleichsregler mitten im Bild - links original, rechts entwickelt. |
| `screenshot-kennlinie.png` | Ausschnitt der Seitenspalte: Kennlinie und Histogramm. |

## Worauf es ankommt

**Nimm ein echtes Foto, nicht das Beispielmotiv.** Das Demobild ist gerechnet,
sein Sonnenband bricht in Treppenstufen - als erstes Bild im README verkauft
das die Emulation unter Wert. Ein Portraet oder eine Abendaufnahme mit einer
Lichtquelle zeigt am meisten: Hauttoene, Lichthof, Korn.

**Fenster auf ungefaehr 1400 Pixel Breite.** Schmaler wird die Seitenspalte
gedraengt, deutlich breiter wirkt das Bild verloren.

**Vor dem Auslesen aufraeumen:** ein Foto geladen, ein Film gewaehlt, keine
Fehlermeldung offen, die Feineinstellung zugeklappt.

**PNG, nicht JPEG.** Oberflaechen mit feinen Linien und Text franst JPEG aus.
Unter 500 KB pro Bild bleiben, sonst laedt das README traege.

Unter Windows: Win+Shift+S, Bereich ziehen, aus der Zwischenablage speichern.

## Fuer die Portfolio-Website

Dieselben Bilder taugen dort auch, aber dort lohnt zusaetzlich ein
Vorher-Nachher-Paar aus **demselben** Foto - einmal original, einmal
entwickelt, gleicher Ausschnitt. Das ist das Bildpaar, das ohne ein Wort
Erklaerung zeigt, was die App macht.
